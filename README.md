# StepCraft — web demo

**Connect the steps. Build your confidence.**

A learning app for beginners who want to build on Solana and with AI.
Five workflow courses, 36 step-by-step puzzles, and a glossary of 134 terms.

**Try it:** https://vergelab2026.github.io/stepcraft-web/

- Runs entirely in your browser. No account, no tracking, no server.
- Progress is saved only in your browser (localStorage).
- Built for the Colosseum Crypto World's Fair Hackathon (Fall 2026) by Tatsuki Ogasawara (Japan).
